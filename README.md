# Portfolio AI Developer – Progetti di Certificazione

Benvenuto nel mio repository portfolio! Questa raccolta include progetti pratici che spaziano dal Machine Learning classico alla Generative AI, fino allo sviluppo Full-Stack e alla gestione di agenti intelligenti.

---

## 🛠️ Competenze Tecniche Acquisite
* **AI & NLP:** Large Language Models (LLM), RAG, Agenti AI, Text Recognition (OCR).
* **Sviluppo Software:** Full-Stack Development, Sincronizzazione File, Automazione Processi.
* **Linguaggi e Strumenti:** Python, Jupyter Notebook, Git, Deployment di modelli AI.

---

## 📂 Indice dei Progetti

Di seguito trovi la descrizione dettagliata di ciascun progetto contenuto nel repository, numerato secondo l'ordine di sviluppo.

### 🤖 Intelligenza Artificiale, NLP & Agenti
* **[1-Algoritmo_motore_ricerca.ipynb](./1-Algoritmo_motore_ricerca.ipynb):** Sviluppo di un motore di ricerca semantico/testuale per il recupero efficiente delle informazioni.
* **[2-Riconosimento_testi_museo.ipynb](./2-Riconosimento_test_museo.ipynb):** Text recognition per il riconoscimento del testo all'interno di contesti museali.
* **[5-Automazione dell'Analisi Documentale con LLM](./5-Automazione%20dell'Analisi%20Documentale%20con%20L...):** Pipeline per l'estrazione automatica di insight e riassunti da documenti complessi utilizzando Large Language Models.
* **[6- Agente AI per la Gestione del Rischio Finanziario](./6-%20Agente%20AI%20per%20la%20Gestione%20del%20Rischio%20Finanzizi...):** Creazione di un agente intelligente autonomo (o sistema multi-agente) per l'analisi dei dati finanziari e la valutazione del rischio.
* **[7- Sintesi automatica di cartelle cliniche.ipynb](./7-%20Sintesi%20automatica%20di%20cartelle%20cliniche.ipynb):** Sistema di NLP applicato al settore Healthcare per il riassunto sicuro e accurato di dati e cartelle cliniche.

### 💻 Sviluppo, Automazione & Deployment
* **[3-deploy-sistema-text-recognition](./3-deploy-sistema-text-recognition):** Ingegnerizzazione e deployment in produzione del sistema di riconoscimento testo (progetto 2), focalizzato su scalabilità e accessibilità tramite API/Web App.
* **[4-Un Sistema per Sincronizzare i File tra Due Computer](./4-Un%20Sistema%20per%20Sincronizzare%20i%20File%20tra%20Due%20C...):** Script/Applicazione per la sincronizzazione sicura e automatizzata di file in ambienti distribuiti.
* **[8- full-stack-dev-project](./8-%20full-stack-dev-project):** Progetto end-to-end che integra un'interfaccia utente (Frontend) con logiche di backend, mostrando la capacità di creare applicazioni complete pronte all'uso.

---

## 🚀 Come Esplorare i Progetti

1. **Notebook Jupyter (`.ipynb`):** Puoi visualizzarli direttamente su GitHub cliccando sui link sopra oppure scaricarli ed eseguirli localmente con `jupyter notebook`.
2. **Applicazioni/Cartelle:** Ogni cartella di progetto contiene un proprio file `README.md` specifico con le istruzioni di installazione e i requisiti software (`requirements.txt`).
